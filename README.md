# Mission Hero

Mission Hero — интерактивное браузерное приключение для детей 4–7 лет: устройство превращается в панель космического корабля, а большая часть игры происходит в комнате. Первым создаём **тестовый прототип одного космического мира** (ориентир 3–5 недель), без монетизации и внешнего ИИ во время игры.

## Вход в проект для любого агента

1. Прочти [AGENTS.md](AGENTS.md) — обязательные правила работы.
2. Проверь [актуальное состояние](docs/PROJECT_STATE.md) и [передачу контекста](docs/HANDOFF.md).
3. Сверься с [задачами](docs/TASKS.md), [дорожной картой](docs/ROADMAP.md), [ТЗ](docs/PRODUCT.md) и [подтверждёнными решениями](docs/DECISIONS.md).
4. Прежде чем менять код, синхронизируйся с GitHub: незапушенные локальные изменения **невидимы** агенту в другом окружении.

**Общая точка синхронизации:** [Hosttik/mission_hero](https://github.com/Hosttik/mission_hero). ChatGPT работает с этим репозиторием через подключение GitHub; Codex — через локальный Git и push/pull. [Протокол](docs/COLLABORATION.md).

> Документ PRODUCT.md — детальный проект ТЗ, который ещё не утверждён полностью; метки [Р], [П], [Т] в нём отличают подтверждённые решения от предложений и гипотез.

## Версии и деплой

Текущая игровая версия: **0.2.0**. [Порядок выпуска](docs/RELEASES.md) требует повышать `VERSION`, синхронно менять `package.json` и фиксировать изменения в `CHANGELOG.md` при каждой новой публикации. GitHub Pages публикуется из `main` через GitHub Actions; код без изменения версии на сайт не попадёт.

- Запуск локально: открой репозиторий через статический HTTP-сервер (например, `python3 -m http.server 8000`) и перейди на `http://localhost:8000`.
- Node.js: минимум 20, для совпадения с CI рекомендуется 22 (в локальной среде есть 22.23.0). Установка npm-зависимостей текущему прототипу не нужна.
- Проверки: `npm test`; `npm run check-release`.
- Сборка: `npm run build`.
- **Опубликованная версия 0.2.0:** [Открыть Mission Hero](https://hosttik.github.io/mission_hero/). Проверена в браузере; [успешный workflow](https://github.com/Hosttik/mission_hero/actions/runs/40085527855), [PR #2](https://github.com/Hosttik/mission_hero/pull/2).

Прототип пока **не готов к самостоятельному тестированию детьми**: голосовые команды не реализованы; список ограничений — в `CHANGELOG.md`.

## Передача без истории чата

Следующему исполнителю достаточно репозитория и поручения «Прочти AGENTS.md и продолжи по docs/PROJECT_STATE.md». До принятия задачи он проверяет активного исполнителя и публикует свой статус в main. Работа строго последовательная. [Проверка протокола](docs/INFRASTRUCTURE_CHECK.md), [план опционального Relay](docs/RELAY_SETUP.md).
