## Что реализовано в 0.1.0

- Кабина с четырьмя интерактивными системами, четырьмя локациями, ресурсами и последствиями;
- пять типов событий (цель — 12), физические задания с вариантами реквизита и пропуском;
- RU/EN текст, короткие звуковые эффекты, старт, пауза, localStorage, свободный режим и 10/20/30 минут;
- чистый JS без npm-зависимостей, Node-тесты движка;
- релизное правило: `VERSION` + `package.json` + `CHANGELOG.md`. Каждый **новый** релиз увеличивает версию.
