## Как обновлять

Обновляй этот файл **в ветке `main`** при изменении активной задачи, передаче, появлении PR и существенном блокере. В нём всегда должны быть: активный агент, ID задачи, branch/PR, результат последней реальной проверки, блокер и один конкретный следующий шаг. Не записывай предполагаемый commit SHA как проверенный.

После каждого редактирования сопоставь текущую задачу с `docs/TASKS.md`. Не заменяй этот файл длинным чат-логом — подробности только в HANDOFF.
