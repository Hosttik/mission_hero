# Mission Hero — Changelog

Все опубликованные на GitHub Pages изменения сопровождаются повышением номера версии в `VERSION` и `package.json` и отдельной записью здесь. Без нового номера workflow не запускает публикацию.

## [0.1.0] — 2026-10-23

### Добавлено
- Первый интерактивный горизонтальный космический кокпит для браузера.
- Базовые системы: навигация по четырём локациям, реактор, сканер и щиты.
- Детерминированные ресурсы корабля и пять событий, включая задания в комнате.
- Выбор заданий с реквизитом/без и пропуск без штрафа.
- Свободный полёт и режимы 10/20/30 минут с мягким завершением.
- Русский и английский текст интерфейса, звуковые сигналы, локальное сохранение и пауза.
- Автоматические проверки движка и релизный pipeline для GitHub Pages.

### Ограничения
- Это первый вертикальный срез, не готовый к тестированию самостоятельности ребёнка: обязательная короткая голосовая озвучка ещё отсутствует.
- Библиотека событий пока содержит 5 из запланированных 12; не реализованы улучшения корабля и второй член экипажа.
- GitHub Pages требует выбора источника «GitHub Actions» в Settings → Pages, если ещё не включён.
